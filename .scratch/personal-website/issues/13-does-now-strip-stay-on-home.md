# Does the now strip stay on home?

Type: grilling
Status: resolved
Blocked by: —

## Question

The original home spec included a "Now" strip between hero and the content index. With the lighter home (hero + recently updated only), should the now strip still appear on home?

1. **Keep on home** — hero → now strip → recently updated. Signals active focus without a click.
2. **Nav only** — drop the strip; `/now` is reachable from header. Home is just hero + recently updated.

## Answer

**Keep on home.** Layout: hero → now strip → recently updated.

**Remove "Now" from header nav** — the strip is the entry point; `/now` remains reachable via the strip's "Full now page" link.
